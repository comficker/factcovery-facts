# factcovery-facts

[English](../README.md) · [Español](README.es.md) · [Français](README.fr.md) · **Deutsch** · [Português](README.pt.md) · [Tiếng Việt](README.vi.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Über 500 kurze, belegte Fun Facts als JSON und CSV, mit kleiner JavaScript-API, CLI und MCP-Server.

Jeder Fakt hat eine Ein-Satz-Zusammenfassung, die geprüfte Quelle, Themen und einen Link zum vollständigen Artikel auf [Factcovery](https://www.factcovery.com), einer Website mit jeden Tag einem neuen interessanten Fakt.

```json
{
  "id": "octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms",
  "title": "Octopuses Have Three Hearts, Blue Blood and Most of Their Neurons in Their Arms",
  "summary": "An octopus has three hearts, blue blood and a nervous system in which most neurons sit outside the brain.",
  "topics": [
    "biology",
    "marine-life",
    "zoology",
    "neuroscience"
  ],
  "source": "https://en.wikipedia.org/wiki/Octopus",
  "factcovery": "https://www.factcovery.com/facts/octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms"
}
```

## Installation

```bash
npm install factcovery-facts
```

## Verwendung

```js
import { randomFact, factOfTheDay, factsByTopic, search } from 'factcovery-facts'

randomFact()            // any fact
randomFact('space')     // a random space fact
factOfTheDay()          // same fact for everyone today
factsByTopic('penguins')
search('octopus')
```

```bash
npx factcovery-facts            # random fact
npx factcovery-facts today      # fact of the day
npx factcovery-facts topics
```

## MCP-Server

Nutze die Fakten in Claude, Cursor oder jedem MCP-Client:

```json
{ "mcpServers": { "factcovery-facts": { "command": "npx", "args": ["-y", "-p", "factcovery-facts", "factcovery-facts-mcp"] } } }
```

Tools: `random_fact`, `fact_of_the_day`, `search_facts`, `facts_by_topic`, `get_fact`, `list_topics`.

## Über Factcovery

[Factcovery](https://www.factcovery.com) veröffentlicht kurze, belegte Fakten über Tiere, Weltraum, Geschichte, Wissenschaft und den menschlichen Körper. Probiere [zufällige Fakten](https://www.factcovery.com/random) oder die [Android-App](https://play.google.com/store/apps/details?id=com.factcovery.app).

Fehler gefunden? [Issue öffnen](https://github.com/comficker/factcovery-facts/issues/new?template=wrong-fact.md) mit einer besseren Quelle.
