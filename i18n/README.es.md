# factcovery-facts

[English](../README.md) · **Español** · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Tiếng Việt](README.vi.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Más de 500 datos curiosos breves y con fuente, en JSON y CSV, con una pequeña API de JavaScript, CLI y servidor MCP.

Cada dato incluye un resumen de una frase, la fuente consultada, los temas y un enlace al artículo completo en [Factcovery](https://www.factcovery.com), un sitio con un dato curioso nuevo cada día.

```json
{
  "id": "octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms",
  "title": "Octopuses Have Three Hearts, Blue Blood and Most of Their Neurons in Their Arms",
  "summary": "An octopus has three hearts, blue blood and a nervous system in which most neurons sit outside the brain.",
  "topics": [
    "biology",
    "marine-life",
    "zoology",
    "neuroscience"
  ],
  "source": "https://en.wikipedia.org/wiki/Octopus",
  "factcovery": "https://www.factcovery.com/facts/octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms"
}
```

## Instalación

```bash
npm install factcovery-facts
```

## Uso

```js
import { randomFact, factOfTheDay, factsByTopic, search } from 'factcovery-facts'

randomFact()            // any fact
randomFact('space')     // a random space fact
factOfTheDay()          // same fact for everyone today
factsByTopic('penguins')
search('octopus')
```

```bash
npx factcovery-facts            # random fact
npx factcovery-facts today      # fact of the day
npx factcovery-facts topics
```

## Servidor MCP

Usa los datos desde Claude, Cursor o cualquier cliente MCP:

```json
{ "mcpServers": { "factcovery-facts": { "command": "npx", "args": ["-y", "-p", "factcovery-facts", "factcovery-facts-mcp"] } } }
```

Tools: `random_fact`, `fact_of_the_day`, `search_facts`, `facts_by_topic`, `get_fact`, `list_topics`.

## Sobre Factcovery

[Factcovery](https://www.factcovery.com) publica datos curiosos breves y con fuente sobre animales, el espacio, historia, ciencia y el cuerpo humano. Prueba los [datos aleatorios](https://www.factcovery.com/random) o la [app para Android](https://play.google.com/store/apps/details?id=com.factcovery.app).

¿Un dato incorrecto? [Abre un issue](https://github.com/comficker/factcovery-facts/issues/new?template=wrong-fact.md) con una fuente mejor.
