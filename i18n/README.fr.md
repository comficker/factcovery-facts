# factcovery-facts

[English](../README.md) · [Español](README.es.md) · **Français** · [Deutsch](README.de.md) · [Português](README.pt.md) · [Tiếng Việt](README.vi.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Plus de 500 anecdotes courtes et sourcées, en JSON et CSV, avec une petite API JavaScript, une CLI et un serveur MCP.

Chaque anecdote comporte un résumé d'une phrase, sa source, ses thèmes et un lien vers l'article complet sur [Factcovery](https://www.factcovery.com), un site qui publie une nouvelle anecdote chaque jour.

```json
{
  "id": "octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms",
  "title": "Octopuses Have Three Hearts, Blue Blood and Most of Their Neurons in Their Arms",
  "summary": "An octopus has three hearts, blue blood and a nervous system in which most neurons sit outside the brain.",
  "topics": [
    "biology",
    "marine-life",
    "zoology",
    "neuroscience"
  ],
  "source": "https://en.wikipedia.org/wiki/Octopus",
  "factcovery": "https://www.factcovery.com/facts/octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms"
}
```

## Installation

```bash
npm install factcovery-facts
```

## Utilisation

```js
import { randomFact, factOfTheDay, factsByTopic, search } from 'factcovery-facts'

randomFact()            // any fact
randomFact('space')     // a random space fact
factOfTheDay()          // same fact for everyone today
factsByTopic('penguins')
search('octopus')
```

```bash
npx factcovery-facts            # random fact
npx factcovery-facts today      # fact of the day
npx factcovery-facts topics
```

## Serveur MCP

Utilisez les anecdotes dans Claude, Cursor ou tout client MCP :

```json
{ "mcpServers": { "factcovery-facts": { "command": "npx", "args": ["-y", "-p", "factcovery-facts", "factcovery-facts-mcp"] } } }
```

Tools: `random_fact`, `fact_of_the_day`, `search_facts`, `facts_by_topic`, `get_fact`, `list_topics`.

## À propos de Factcovery

[Factcovery](https://www.factcovery.com) publie des faits courts et sourcés sur les animaux, l'espace, l'histoire, la science et le corps humain. Essayez les [faits aléatoires](https://www.factcovery.com/random) ou l'[application Android](https://play.google.com/store/apps/details?id=com.factcovery.app).

Une erreur ? [Ouvrez une issue](https://github.com/comficker/factcovery-facts/issues/new?template=wrong-fact.md) avec une meilleure source.
