# factcovery-facts

[English](../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · **Tiếng Việt** · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Hơn 500 sự thật thú vị ngắn gọn, có nguồn, dạng JSON và CSV, kèm API JavaScript nhỏ, CLI và MCP server.

Mỗi fact có tóm tắt một câu, nguồn đã đối chiếu, chủ đề và liên kết tới bài đầy đủ trên [Factcovery](https://www.factcovery.com), trang mỗi ngày một sự thật thú vị mới.

```json
{
  "id": "octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms",
  "title": "Octopuses Have Three Hearts, Blue Blood and Most of Their Neurons in Their Arms",
  "summary": "An octopus has three hearts, blue blood and a nervous system in which most neurons sit outside the brain.",
  "topics": [
    "biology",
    "marine-life",
    "zoology",
    "neuroscience"
  ],
  "source": "https://en.wikipedia.org/wiki/Octopus",
  "factcovery": "https://www.factcovery.com/facts/octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms"
}
```

## Cài đặt

```bash
npm install factcovery-facts
```

## Cách dùng

```js
import { randomFact, factOfTheDay, factsByTopic, search } from 'factcovery-facts'

randomFact()            // any fact
randomFact('space')     // a random space fact
factOfTheDay()          // same fact for everyone today
factsByTopic('penguins')
search('octopus')
```

```bash
npx factcovery-facts            # random fact
npx factcovery-facts today      # fact of the day
npx factcovery-facts topics
```

## MCP server

Dùng dữ liệu trong Claude, Cursor hoặc client MCP bất kỳ:

```json
{ "mcpServers": { "factcovery-facts": { "command": "npx", "args": ["-y", "-p", "factcovery-facts", "factcovery-facts-mcp"] } } }
```

Tools: `random_fact`, `fact_of_the_day`, `search_facts`, `facts_by_topic`, `get_fact`, `list_topics`.

## Về Factcovery

[Factcovery](https://www.factcovery.com) đăng các sự thật ngắn, có nguồn về động vật, vũ trụ, lịch sử, khoa học và cơ thể người. Xem [fact ngẫu nhiên](https://www.factcovery.com/random) hoặc [app Android](https://play.google.com/store/apps/details?id=com.factcovery.app).

Thấy fact sai? [Mở issue](https://github.com/comficker/factcovery-facts/issues/new?template=wrong-fact.md) kèm nguồn tốt hơn.
