# factcovery-facts

[English](../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Português** · [Tiếng Việt](README.vi.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Mais de 500 curiosidades curtas e com fonte, em JSON e CSV, com uma pequena API JavaScript, CLI e servidor MCP.

Cada curiosidade tem um resumo de uma frase, a fonte consultada, os temas e um link para o artigo completo no [Factcovery](https://www.factcovery.com), um site com uma curiosidade nova todos os dias.

```json
{
  "id": "octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms",
  "title": "Octopuses Have Three Hearts, Blue Blood and Most of Their Neurons in Their Arms",
  "summary": "An octopus has three hearts, blue blood and a nervous system in which most neurons sit outside the brain.",
  "topics": [
    "biology",
    "marine-life",
    "zoology",
    "neuroscience"
  ],
  "source": "https://en.wikipedia.org/wiki/Octopus",
  "factcovery": "https://www.factcovery.com/facts/octopuses-have-three-hearts-blue-blood-and-neurons-throughout-their-arms"
}
```

## Instalação

```bash
npm install factcovery-facts
```

## Uso

```js
import { randomFact, factOfTheDay, factsByTopic, search } from 'factcovery-facts'

randomFact()            // any fact
randomFact('space')     // a random space fact
factOfTheDay()          // same fact for everyone today
factsByTopic('penguins')
search('octopus')
```

```bash
npx factcovery-facts            # random fact
npx factcovery-facts today      # fact of the day
npx factcovery-facts topics
```

## Servidor MCP

Use as curiosidades no Claude, Cursor ou qualquer cliente MCP:

```json
{ "mcpServers": { "factcovery-facts": { "command": "npx", "args": ["-y", "-p", "factcovery-facts", "factcovery-facts-mcp"] } } }
```

Tools: `random_fact`, `fact_of_the_day`, `search_facts`, `facts_by_topic`, `get_fact`, `list_topics`.

## Sobre o Factcovery

O [Factcovery](https://www.factcovery.com) publica fatos curtos e com fonte sobre animais, espaço, história, ciência e o corpo humano. Experimente os [fatos aleatórios](https://www.factcovery.com/random) ou o [app Android](https://play.google.com/store/apps/details?id=com.factcovery.app).

Achou um erro? [Abra uma issue](https://github.com/comficker/factcovery-facts/issues/new?template=wrong-fact.md) com uma fonte melhor.
